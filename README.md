# FitTrack VN
App web/PWA tiếng Việt: tập tạ, cardio, cân nặng, dinh dưỡng. Không cần build, không cần server; dữ liệu lưu trên máy (localStorage).

## Chạy thử
    python3 -m http.server 8080   # rồi mở http://localhost:8080

## Đưa lên điện thoại
Đẩy cả thư mục lên Vercel / Netlify / GitHub Pages (site tĩnh). Mở link trên điện thoại,
chọn "Thêm vào Màn hình chính" để dùng như app và chạy offline.
